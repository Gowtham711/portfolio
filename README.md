## 📱 Responsive Design System

The application is engineered with a mobile-first responsive architecture:

| Breakpoint Range | Target Devices | Optimization Highlights |
| :--- | :--- | :--- |
| **`<= 375px`** | Ultra-compact phones (iPhone SE, Galaxy Mini) | Single column layout, scaled font typography, compact padding |
| **`376px – 480px`** | Standard modern smartphones (iPhone 14/15, Pixel) | Touch targets ≥ 44px, full-bleed modals, thumb-friendly buttons |
| **`481px – 768px`** | Phablets & Small Tablets | 2-column skills grid, horizontal scroll tabs, collapsible menus |
| **`769px – 1024px`** | Tablets & Small Laptops (iPad Pro, Surface) | Adaptive bento grid, 2-column project cards, flexible modal views |
| **`1025px – 1440px+`** | Desktop monitors & Large screens | Multi-column Bento grid, high-res canvas previews, hover micro-effects |

- **Zero Overflow**: Fully enforced `overflow-x: hidden` with fluid clamp typography (`clamp()`) and percentage-based auto-adjusting widths.
- **Accessibility**: Includes support for `prefers-reduced-motion: reduce` and optimized `@media print` stylesheets.

## 🚀 Getting Started & Local Setup

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari).
- Python 3.x (optional, for local HTTP server) or Node.js / Live Server.

### Method 1: Python Built-in Server (Recommended)
```bash
# 1. Clone the repository
git clone https://github.com/Gowtham711/portfolio1.git

# 2. Navigate to project directory
cd portfolio1

# 3. Start a local server
python -m http.server 8000
```
Open your browser and navigate to: `http://localhost:8000`

### Method 2: Node.js `npx serve`
```bash
npx serve .
```

### Method 3: VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html` and select **"Open with Live Server"**.

## 🌐 Deployment Guide

### Deploying to GitHub Pages
1. Push all files to your GitHub repository:
   ```bash
   git add .
   git commit -m "feat: complete responsive portfolio & verified documentation"
   git push origin main
   ```
2. In your GitHub repository, navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### Deploying to Vercel / Netlify
- Simply drag and drop the project folder into [Netlify Drop](https://app.netlify.com/drop) or import the Git repository in [Vercel](https://vercel.com). No build command is required.
